Sample PBQ-style task

Scenario: A user reports that their laptop may have malware. Put the incident response actions in a sensible first-response order.

1. Preserve evidence and document actions
2. Isolate the affected device from the network
3. Escalate to the security team
4. Begin eradication only after containment and analysis

A strong order starts with isolation and escalation, while preserving evidence and documenting actions throughout the response.
