Encryption

Protects confidentiality by making data unreadable without the correct key.

Hashing

Supports integrity by creating a fixed output that changes when the original data changes.

Digital signatures

Support integrity, authentication, and non-repudiation by proving who signed data.

Sample Security+ cryptography question

Question: Which cryptographic method is best for checking whether a file changed after download?

A. Hashing
B. NAT
C. Load balancing
D. Geofencing

Answer: A. Hashing

A hash value changes when file contents change, so it is useful for integrity checks.
