Sample Security+ daily question

Question: Which activity best supports non-repudiation?

A. Hashing a password
B. Digitally signing a transaction
C. Compressing a file
D. Masking sensitive data

Answer: B. Digitally signing a transaction

A digital signature can help prove who signed data and whether it was changed afterward.
