CIA triad

Confidentiality protects secrecy, integrity protects correctness, and availability keeps systems usable.

Least privilege

Users and services should receive only the access they need to complete the task.

Defense in depth

Use layered controls so one failed control does not expose the whole environment.

Sample Security+ notes question

Question: A note says hashing verifies integrity, while encryption protects confidentiality. Which statement is correct?

A. Hashing creates a fixed-length digest
B. Hashing always decrypts data
C. Encryption never uses keys
D. Integrity means hiding data from everyone

Answer: A. Hashing creates a fixed-length digest

Security+ expects clear keyword separation: hashing supports integrity; encryption supports confidentiality.
