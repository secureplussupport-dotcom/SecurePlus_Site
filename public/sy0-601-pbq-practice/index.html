Original sample PBQ-style task

Build a narrow remote-administration rule

Scenario: A Linux server at 10.20.40.10 must accept SSH only from the management subnet 10.20.30.0/24. All other traffic attempting to reach SSH on that server must be blocked.

Place the rules in a sensible top-to-bottom order:

1. Permit TCP from 10.20.30.0/24 to 10.20.40.10 on destination port 22.
2. Deny TCP from any other source to 10.20.40.10 on destination port 22.

Why: the narrow allow rule must be evaluated before the broader deny. The design applies least privilege by limiting both the source network and destination service.
